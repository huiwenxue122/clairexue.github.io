# Claire Xue — Portfolio

Personal portfolio site for **Claire Xue**, AI Engineer.

- **Live site:** https://clairexue.me
- **Stack:** React (Create React App), React Router, styled-components

## Local development

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

## Deploy (GitHub Pages)

```bash
npm run deploy
```

`homepage` in `package.json` is set to the custom domain. Static assets and SEO metadata live under `public/` (including `og-image.png`, `manifest.json`, and `index.html`).
